# SFQ-0002 Flint-Order Receiver-Readiness Disposition

## Boundary

This dependent disposition asks only whether the later authority, validation,
and stop objects admitted from EPA's January 21, 2016 emergency order change
the existing source-local-completion requirement for receiver review.

It does not backdate the order into an earlier complaint chain; infer complaint
custody, complaint-specific authority, disposition, validation treatment, stop
status, or causal relevance; merge the Flint and Texas chains; broaden
`SFQ-0002`; establish recurrence or a shared mechanism; accept schema; assign
blame or duty; prescribe a remedy; create receiver work; or request action.

## Controlling Owner Evidence

`SFQ-0002-DISPOSITION-0004-RECEIVER-READINESS` requires source-local
completion because the bounded Flint chain still lacks decision-time custody,
authority, validation, disposition, stop, and causal links. The Texas chain
remains separately incomplete, and East Palestine supplies only a distinct
authority-conversion pressure.

`SFQ-0002-FLINT-ORDER-LINK-REVIEW-0001` supports later EPA Section 1431
authority, corrosion-control and source-transition validation objects, and
written termination conditions. That review explicitly refuses to use the
later order as proof of how one earlier complaint was held, received,
validated, dispositioned, stopped, or made causally relevant.

## Disposition

`keep_source_local_completion_required`.

A later authority and stop object does not complete an earlier complaint
chain. Keep `SFQ-0002` unmodified, preserve the Texas chain separately, retain
Mechanism Design fit as candidate-only, and create no receiver work.

The remaining Flint evidence requirement is one source-local earlier complaint
object with supported custody, complaint-specific authority, disposition,
validation treatment, stop status, and causal relevance. Every unsupported
link remains `unknown`.

## Alternatives, Counterevidence, And Falsifier

The later order is counterevidence to treating Flint authority, validation, or
stop controls as permanently absent. Its chronology is counterevidence to
using those controls as proof of the earlier complaint's treatment. Drinking-
water treatment, corrosion control, public health, civil rights, federal and
state oversight, emergency authority, legal, and public-communication accounts
remain sovereign.

Reverse this disposition only if source-local evidence independently connects
one earlier complaint through custody, complaint-specific authority,
disposition, then-current validation treatment, unresolved stop, and causal
relevance without borrowing the later order backward. Narrow or retire the
inquiry if repeated bounded source reviews cannot complete that chain without
inference or if the relevant observation was timely resolved through an
accountable route.
