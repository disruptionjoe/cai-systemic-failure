## Disposition

`distinct_but_relevant`.

Technical dissent does not become a third admitted observation type inside
`SFQ-0002`, and this test does not support expanding the inquiry. It is
relevant comparison pressure on the inquiry's existing authority-conversion,
disposition, and accountable-stop questions because `SF-FN-0001` makes a
different correction-route shape visible.

## Scope Retained

Keep `SFQ-0002` unmodified. Preserve evidence type, standing, source, custody,
recipient, authority, timing, validation burden, disposition, stop condition,
and domain absorber as separate links. A later Challenger trace may inform
comparison only through independently supported links.

## Scope Refused

This test refuses to recast technical dissent as resident evidence, infer a
complete Challenger trace from the bounded synthesis, count case plurality or
severity as mechanism evidence, add a core field, promote schema, prescribe a
remedy, change receiver fit, or authorize external action.

## Falsifier

Revise this disposition if source-preserving evidence shows that Challenger
technical dissent is fully represented by the inquiry's operational-
observation class without erasing standing or authority differences, or that
its dissent path bears no supported relation to the inquiry's validation,
disposition, and stop-condition objects. Expansion would require independently
supported evidence that a distinct third evidence class changes the inquiry's
answerable mechanism rather than merely resembling it.
