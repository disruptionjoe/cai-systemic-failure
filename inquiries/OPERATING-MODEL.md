# Systemic-Failure Inquiry Operating Model

The governed object is an inquiry into a candidate systemic-failure seam.

```text
intake -> problem shape -> compare models -> validate sources and
contradictions -> package -> route or retain
```

Topology, prior-art, contradiction, and inquiry-package work are distinct
treatments within Lane 1. They do not imply that the mechanism is proven or
that a downstream owner has accepted it.

An inquiry closes locally only with a supported no-seam disposition or a
source-backed package routed to a named receiving owner. The return remains
open until that owner accepts, narrows, rejects, or requests revision. Lane A
keeps inquiry status, claim boundaries, and unresolved returns coherent.
