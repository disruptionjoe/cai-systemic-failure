# Fort Totten / Amtrak 188 Train-Control Boundary

## Boundary

This comparison preserves a bounded relation between Fort Totten's false-
vacant track-circuit state and continued permissive automatic speed commands
in `NTSB/RAR-10/02` and Amtrak Train 188's unenforced permanent curve
restriction and absent automatic speed intervention in `NTSB/RAR-16/02`.

It does not infer recurrence, one train-control or operator mechanism, complete
custody, shared authority, relative causal weight, schema pressure, blame,
duty, remedy, acceptance, receiver work, liability, health causation, or
external action.

## Decision, Counterevidence, And Falsifier

Decision: `prepare_bounded_forttotten_amtrak_train_control_comparison` while
preserving separate detection, command, restriction, and intervention paths.

The reports support one bounded comparison: automatic train-control safety
depends on what condition is represented, what command or restriction follows,
and whether a capable detection or enforcement layer is actually
institutionalized. Fort Totten exposes a false-vacant representation that
continued permissive commands; Amtrak 188 exposes a known permanent
restriction without automatic enforcement. Different failure physics, signal
states, operating actions, assurance methods, implementation loci, oversight,
standing, and consequences are counterevidence to recurrence or one shared
mechanism.

Falsify or materially narrow this comparison if closer official-source review
shows that the Fort Totten false-vacant state did not continue speed commands
to the following train or that automatic enforcement of Amtrak 188's permanent
restriction would not have prevented the derailment. Reject any stronger
comparison that imports common custody, authority, correction, implementation,
causal weight, recurrence, or verified control effect.
