# Arkema / Texas 2021 Common-Mode Resource Boundary

## Boundary

This comparison tests only whether the bounded Arkema Crosby and Texas 2021
records support one common extreme-weather-to-resource-and-control chain. It
uses the official-source material already bounded in `SF-0006` and `SF-0011`.

It does not equate a facility safeguard system with a regional interdependent
electric and gas system; infer complete stress-knowledge custody, accountable
authority, disposition, stop condition, implementation, or causal weight;
establish recurrence or a shared mechanism; assign blame or duty; prescribe a
remedy; create receiver work; or authorize external action.

## Source Set

- Arkema: U.S. Chemical Safety and Hazard Investigation Board, *Organic

- Texas 2021: FERC, NERC, and Regional Entity staff, *The February 2021 Cold

## Decision, Counterevidence, And Falsifier

Decision: `preserve_separate_common_mode_resource_boundaries`.

Both records preserve extreme-weather stress and interacting resource
dependencies, but they do not independently establish the same stress
knowledge, custody, accountable authority, disposition, stop condition, or
control effect. Arkema's common-mode flood dependence is a facility safeguard
failure. Texas 2021's electric-gas coupling is a regional interdependence whose
multi-cause outage account includes freezing, fuel, preparation, and operating
constraints. Those distinctions are counterevidence to recurrence by analogy.

Reopen a shared common-mode-resource candidate only if source-local evidence
in both cases establishes the same bounded stress object, resource dependency,
accountable authority, disposition, stop condition, and control effect without
borrowing a link across cases. Falsify this negative boundary if both complete
chains are independently supported; narrow it if closer source review changes
one bounded record. Complete custody, authority, disposition, stop conditions,
relative causal weight, recurrence, schema fit, liability, and remedy efficacy
remain unknown.
