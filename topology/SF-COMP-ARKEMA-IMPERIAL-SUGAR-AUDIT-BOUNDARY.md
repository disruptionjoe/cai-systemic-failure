# Arkema / Imperial Sugar Audit-Object Boundary

## Boundary

This comparison tests only whether the bounded Arkema and Imperial Sugar
records support a common source-local insurer or audit translation object. It
uses the official-source material already bounded in `SF-0010` and `SF-0011`.

It does not equate an insurer report that identified flood exposure with an
assessment that did not adequately address combustible dust; infer complete
distribution, accountable receipt, decision-time custody, authority,
disposition, implementation, or causal weight; merge the event mechanisms;
establish recurrence or provisional-screen fit; assign blame or duty;
prescribe a remedy; create receiver work; or authorize external action.

## Decision, Counterevidence, And Falsifier

Decision: `preserve_separate_audit_boundaries`.

The records support the existence of two distinct insurer objects. They do not
both support the required accountable recipient, decision-time custody,
disposition, implementation, and control-effect links. Arkema's common-mode
flood dependence and Imperial Sugar's combustible-dust control layers are
source-backed counterevidence to treating severe outcomes, insurer presence,
or incomplete custody as one shared mechanism.

Reopen a bounded audit-translation comparison only if source-local evidence in
both cases identifies the assessment object, accountable recipient,
decision-time custody, disposition, implementation, and control effect without
borrowing a link across cases. Falsify this negative result if closer official-
source review supplies those complete links in both records; narrow either
record if it changes a source fact or unknown preserved here.

## Result

The comparison closes the prepared gate with a source-preserving negative
result. It creates no recurrence, shared mechanism, schema pressure, blame,
duty, remedy, acceptance, receiver work, or external action.
